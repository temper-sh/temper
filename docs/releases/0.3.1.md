# Temper 0.3.1

Temper installs and manages a local AI stack on Apple Silicon Macs. Choose
model presets in a guided setup; Temper downloads the files, starts the models
and serves them to chat and coding apps through one local OpenAI-compatible
API. This release adds one command for your own presets.

## Upgrade from 0.3.0

```sh
brew upgrade temper-sh/temper/temper
```

Nothing else changes: the catalog, your Temper folder and your preset files
stay as they are, and a running layout keeps running.

## What changed since 0.3.0

- **`temper preset plan ID`** shows what installing one of your presets on
  this Mac would download, which files are already in your Hugging Face cache
  or in Temper, the disk it needs and whether Temper can install it here. It
  is the same review `temper init --dry-run` gives for catalog presets, and it
  saves and downloads nothing. With `--json` it prints `temper-preset-plan/v1`.
  [Field Kit](https://github.com/temper-sh/field-kit) uses it to show the
  downloads of a trial with other weights before you agree to run it. See
  [Your own presets](https://github.com/temper-sh/temper/blob/v0.3.1/docs/contracts/user-presets.md).

## Compatibility

Temper keeps these working across its releases: the published catalog files,
your Temper folder (`configuration.json`, the stored catalog and
`temper-root.json`) and your preset files in `presets.d` (`temper-preset/v1`).
Command output, including `--json`, may change in any release; scripts that
use it should pin an exact Temper version.

## Distribution and limits

The direct macOS ARM64 ZIP on this page is signed and notarized. Homebrew
provides a source formula and a separate ARM64 bottle.

Memory estimates and recommendations do not establish fit or answer quality on
every Mac. Serving is local to your Mac; Temper has no telemetry or background
updater.

Report problems at
[github.com/temper-sh/temper/issues](https://github.com/temper-sh/temper/issues).
