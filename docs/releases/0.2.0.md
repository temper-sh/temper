# Temper 0.2.0

Temper installs and manages a local AI stack on Apple Silicon Macs. Choose
model presets in a guided setup; Temper downloads the files, starts the models
and serves them to chat and coding apps through one local OpenAI-compatible
API. In this release, setup installs and starts in one step, and every command
answers in plain words.

## Get started

You need an Apple Silicon Mac and the Hugging Face tool `hf` (for example
`brew install hf`); Temper uses it to download models. We also advise
installing the [Pi](https://github.com/earendil-works/pi) coding agent first
(`curl -fsSL https://pi.dev/install.sh | sh`), so you can try your models as
soon as they start.

```sh
brew tap temper-sh/temper https://github.com/temper-sh/temper
brew trust --formula temper-sh/temper/temper
brew install temper-sh/temper/temper
temper init
```

On Homebrew versions before 7, omit `brew trust`. In setup, choose presets,
check the review and choose **Install and start**. When it finishes, Temper
prints the address and the model IDs. Add them to Pi or another app as an
OpenAI-compatible provider with the base URL `http://127.0.0.1:8080/v1`. The
[setup guide](https://github.com/temper-sh/temper/blob/v0.2.0/docs/contracts/init.md)
covers configuration, layout changes and recovery.

## Upgrade from 0.1.0

Please upgrade: the catalog published with this release needs Temper 0.2.0 for
every preset except the Ettin reranker. Your `~/.temper` folder keeps working.
Stop the running layout first, because 0.1.0 starts models through the
Homebrew copy of Temper that the upgrade replaces:

```sh
temper layout stop
brew upgrade temper-sh/temper/temper
temper update
temper layout activate default
```

`temper update` shows what changes for each saved preset and installs it. Use
your own layout's ID if it is not `default`.

If you stay on 0.1.0, your saved presets keep running with the exact files
they use today. `temper update` then keeps them unchanged and says they need
Temper 0.2.0 or newer, so you get no newer presets or software.

## What changed since 0.1.0

- **Install and start in one step.** The review's first button installs the
  missing files and starts the default layout; it shows the download size.
  Saving without installing is the second choice.
- **Plain output.** Commands say what happened and what to do next. Scripts
  get one JSON document with `--json`. Every command has a readable `--help`;
  a mistyped preset ID gets the closest match.
- **Clear disk and memory needs.** The review shows the disk space still
  needed, including the cache Splash presets build on first start. Layouts
  show the memory used at start and the least memory the largest preset needs.
- **Updates that finish the job.** `temper update` installs what changed and
  restarts the running layout. Upgrading Temper no longer breaks a running
  layout.
- **`temper cleanup`** removes old engine releases and caches that no saved
  preset and no running layout uses. `--dry-run` lists them first.
- **Calmer setup screens.** Each part of the wizard has its own colors, the
  review lists one line per preset, and Esc on the first screen no longer
  drops your choices.
- **Longer answers.** Chat presets no longer set a separate output limit. An
  answer, including its reasoning, can use the context left after your input.
  Your app can still ask for a smaller limit, and the context setting still
  applies.
- **A new answer each time.** Presets no longer fix the sampling seed, so
  asking the same question again can give a different answer.

## Compatibility

The compatibility promise starts with this release. Temper 0.2 keeps two
things working across its releases: the published catalog files (catalog,
channel and signatures) and your Temper folder (`configuration.json`, the
stored catalog and `temper-root.json`). Everything else in the folder is
cache. Command output, including `--json`, `machine facts`, `temper software`
and `catalog compile|describe` may change in any release; scripts that use
them should pin an exact Temper version.

## Distribution and limits

The direct macOS ARM64 ZIP on this page is signed and notarized. Homebrew
provides a source formula and a separate ARM64 bottle.

Memory estimates and recommendations do not establish fit or answer quality on
every Mac. Fit on 8/16 GB Macs is not verified. Model downloads can be many
gigabytes. Serving is local to your Mac; Temper has no telemetry or background
updater. To uninstall, see
[Uninstall and disk space](https://github.com/temper-sh/temper/blob/v0.2.0/README.md#uninstall-and-disk-space).

Report problems at
[github.com/temper-sh/temper/issues](https://github.com/temper-sh/temper/issues).
