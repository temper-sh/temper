# Temper 0.3.2

This patch fixes Rapid MLX presets that need a separate MTP head: the extra
weights used to propose tokens during speculative decoding. Temper now pins,
downloads and verifies that file, then passes its exact local path to Rapid.

## Upgrade from 0.3.1

Finish open Field Kit studies and stop active Temper layouts before upgrading.

```sh
brew update
brew upgrade temper-sh/temper/temper
temper version
```

## What changed

- **Explicit Rapid MTP heads.** A text-only Rapid preset can select a pinned
  single-file safetensors head independently of its complete target model.
  The head participates in download planning, installation and execution
  identity. Rapid receives the verified local file through
  `--speculative-config`, including paths containing spaces or quotes.
- **Validation before installation.** Missing heads, incomplete target
  snapshots and incompatible draft selections are rejected. Existing embedded
  MTP presets keep their command behavior.

The [execution-lock contract](https://github.com/temper-sh/temper/blob/v0.3.2/docs/contracts/execution-lock.md)
describes the composition. Actual head activation, speed, memory use and answer
quality still need measurement on the intended model and machine.

## Compatibility and distribution

Existing catalog files, Temper roots and user presets remain supported.
Upgrading the CLI leaves saved model selections unchanged. Scripts consuming
command output should pin an exact Temper version.

The direct macOS ARM64 ZIP is signed and notarized. Homebrew provides a source
formula and a separate ARM64 bottle.
