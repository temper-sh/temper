# Temper 0.2.0-alpha.1

A test build of Temper 0.2.0. Setup now installs and starts your models in
one step, and every command answers in plain words. Please try it on a fresh
setup and tell us what was unclear or broke.

## Try it

You need an Apple Silicon Mac and the Hugging Face tool `hf` (for example
`brew install hf`). We also advise installing the
[Pi](https://github.com/earendil-works/pi) coding agent first
(`curl -fsSL https://pi.dev/install.sh | sh`), so you can try your models as
soon as they start.

This alpha is only on this page, as a signed and notarized ZIP; Homebrew
stays on 0.1.0. Install it and open setup:

```sh
curl -fLO https://github.com/temper-sh/temper/releases/download/v0.2.0-alpha.1/temper_0.2.0-alpha.1_darwin_arm64.zip
ditto -x -k temper_0.2.0-alpha.1_darwin_arm64.zip .
sudo mkdir -p /usr/local/bin
sudo cp temper_0.2.0-alpha.1_darwin_arm64/temper /usr/local/bin/
temper version
temper init
```

`temper version` must print `temper 0.2.0-alpha.1`. If it prints 0.1.0,
Homebrew's Temper comes first in your `PATH`; run
`brew uninstall temper-sh/temper/temper` or call `/usr/local/bin/temper`.

In setup, choose presets, check the review and choose **Install and start**.
When it finishes, Temper prints the address and the model IDs. Add them to Pi
or another app as an OpenAI-compatible provider with the base URL
`http://127.0.0.1:8080/v1`.

## What changed since 0.1.0

- **Install and start in one step.** The review's first button installs the
  missing files and starts the default layout; it shows the download size.
  Saving without installing is the second choice.
- **Plain output.** Commands say what happened and what to do next. Scripts
  get one JSON document with `--json`. Every command has a readable `--help`;
  a mistyped preset ID gets the closest match.
- **Clear disk and memory needs.** The review shows the disk space still
  needed, including the cache Splash presets build on first start. Layouts
  show the memory used at start and the least memory the largest preset needs.
- **Updates that finish the job.** `temper update` installs what changed and
  restarts the running layout. Upgrading Temper no longer breaks a running
  layout.
- **`temper cleanup`** removes old engine releases and caches that no saved
  preset and no running layout uses. `--dry-run` lists them first.
- **Calmer setup screens.** Each part of the wizard has its own colors, the
  review lists one line per preset, and Esc on the first screen no longer
  drops your choices.

## Limits

- The compatibility promise starts with 0.2.0. Temper 0.2.0 may refuse a
  folder made by this alpha; then set up again in a fresh folder.
- Memory estimates do not prove that a preset fits your Mac. Fit on 8/16 GB
  Macs is not verified.
- Model downloads can be many gigabytes.
- Colors and wording may still change before 0.2.0.

Report problems at
[github.com/temper-sh/temper/issues](https://github.com/temper-sh/temper/issues).
