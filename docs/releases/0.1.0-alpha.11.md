# Temper 0.1.0-alpha.11

This alpha adds reusable presets, named layouts and the host commands needed by
Field Kit's Qwen machine study revision 4. It also removes retired alpha formats.

## Presets and layouts

- Choose from five Recommended presets or the full catalog. Each preset keeps
  its exact weights, engine, template and settings. Nothing starts selected.
- Compose named layouts with independent availability, startup loading and
  default-model choices. Shared software and weights are prepared once.
- Activate, inspect and stop managed layouts explicitly. Idle models can unload
  and reload; preparation alone starts no service.
- Signed catalog sequence 3 contains the current v3 presets. Update the catalog
  before creating a configuration with this release.

## Experiment support

- `catalog compile --preset ID` produces a native execution-lock v3.
- `execution configure` derives context, output and optional Splash memory
  limits from a frozen lock without changing software, weights or templates.
- The Qwen study uses exact Splash, llama.cpp, Rapid MLX and vLLM Metal
  compositions, auxiliary Python environments and supervised process identities.
- Software receipts are reusable across execution-setting changes when the
  installed software is unchanged.

## Upgrade boundary

Catalog v1/v2, execution-lock v1/v2, manifest v1, Selection files, the separate
software catalog, old setup pairs and compatibility exports are unsupported.
Use a fresh Temper root, recompile current presets and recreate saved
configurations. There is no importer for an old catalog store or configuration.

```sh
temper catalog update --root "$HOME/.temper-alpha11"
temper init --root "$HOME/.temper-alpha11"
```

Keep unfinished Field Kit runs in their original checkout with their producing
Temper executable. Study revision 4 needs its regenerated package and this host;
do not migrate or replay earlier runs.

## Evidence and limits

Hermetic Go and Field Kit checks cover the current contracts. Existing bounded
M5 measurements retain their exact configurations. First revision 4 study runs
on eligible 36 GiB and 48 GiB+ machines remain pending. Memory predictions and
recommendation membership do not establish universal fit or model quality.

The distribution target is macOS on Apple Silicon. Public assets are Developer
ID-signed and notarized by the release workflow; local rehearsal archives are
unsigned and are not contributor downloads.
