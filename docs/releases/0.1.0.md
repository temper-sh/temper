# Temper 0.1.0

Temper's first public release installs and manages a local AI stack on Apple
Silicon Macs. Choose model presets, prepare their files, and serve them to chat
or coding apps through one local OpenAI-compatible API.

## Get started

Install the Hugging Face command-line tool `hf` first (for example
`brew install hf`); Temper uses it to download models. Then:

```sh
brew tap temper-sh/temper https://github.com/temper-sh/temper
brew trust --formula temper-sh/temper/temper
brew install temper-sh/temper/temper
temper init
```

On Homebrew versions before 7, omit `brew trust`. After choosing presets and
preparing their installation, start the suggested layout:

```sh
temper layout activate default
```

Use `http://127.0.0.1:8080/v1` as your app's API base URL and an included
preset's ID as the model name. The
[setup guide](https://github.com/temper-sh/temper/blob/v0.1.0/docs/contracts/init.md)
covers configuration, layout changes and recovery.

## Included

- **Presets.** Each preset binds exact model files, an engine, a chat
  template and tuned settings. The first catalog has eighteen presets, with
  llama.cpp b11381/b11396, llama-swap v262, Splash 1.1.0 and CrispEmbed
  v0.17.11. [Compare the choices](https://temper-sh.github.io/catalog/).
- **Tabs from the catalog.** **General** and **Specialist** hold curated
  recommendations; Specialist is grouped by task (extraction, reranking,
  translation) with an explanation of each. **Other** holds the remaining
  choices. A preset this Temper cannot use is shown disabled with the reason.
- **Settings per Mac.** A preset can carry settings for different memory
  sizes; setup picks the one for your Mac. You can change context and choose
  CPU or GPU where both are offered; these choices are kept on update.
- **Specialists.** NuExtract3 for text and image extraction, Ettin 150M for
  compact English CPU reranking, Qwen3 Reranker 0.6B for multilingual
  reranking, TranslateGemma 4B/12B/27B and Tiny Aya Global/Water/Fire/Earth for
  translation. The
  [request guide](https://github.com/temper-sh/temper/blob/v0.1.0/docs/SPECIALISTS.md)
  covers their input formats.
- **Layouts.** The wizard suggests one editable **Default** layout with all
  selected presets. Models load on request and unload when idle.
- **Updates you control.** `temper update` downloads the newest signed catalog
  and shows, per saved preset, what changes (old → new) before you prepare it.
  `temper update --software` changes only router and engine releases.
  `temper configure --software latest` follows the newest upstream releases,
  falling back to the tested ones with a visible reason. Nothing updates in
  the background.
- **Licenses.** Every model choice shows its license in selection and review,
  with a link to guidance or the publisher's terms.
- **Shared model files.** Model weights stay in the shared Hugging Face cache,
  so other tools can use them. If the cache moves, preparation links the
  models from the new place and never writes into the old one.
- **Exact execution locks** let scripts and experiments run one preset with
  fixed inputs, separate from your everyday layouts.

## Compatibility

Temper 0.1 promises two things across its releases: the published catalog
files (catalog, channel and signatures) and your Temper folder
(`configuration.json`, the stored catalog and `temper-root.json`). Everything
else in the folder is cache. Command output, `machine facts`, `temper
software` and `catalog compile|describe` may change in any release; scripts
that use them should pin an exact Temper version.

A folder made by a pre-release Temper is refused. Stop its layout, then start
in a fresh folder and select your presets again. Keep unfinished experiments
with the Temper executable and inputs that created them.

## Distribution and limits

The direct macOS ARM64 ZIP is signed and notarized. Homebrew provides a source
formula and a separate ARM64 bottle.

Memory estimates and recommendations do not establish fit or answer quality on
every Mac. Fit on 8/16 GB machines is not verified. Serving is local to your
Mac; Temper has no telemetry or background updater. To uninstall, see
[Uninstall and disk space](https://github.com/temper-sh/temper/blob/v0.1.0/README.md#uninstall-and-disk-space).
